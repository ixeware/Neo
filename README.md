# ВЫСОТКА — Атаги против Курчалоя

Стратегия в реальном времени про вечную войну Старых Атагов и Курчалоя за самое высокое здание. В Курчалое стоит пятиэтажка, «местный Бурдж-Халифа». В Атагах трёхэтажка, четвёртый этаж Ислам до сих пор ищет.

Карта настоящая. Это кусок Чечни 40 × 27 км от Старых Атагов до Курчалоя:

- рельеф из AWS Terrain Tiles;
- леса, поля, застройка и вода из ESA WorldCover 2021 (сетка 10 м);
- дороги, улицы, железнодорожные ветки, речки и каналы из OpenStreetMap (© участники OpenStreetMap, ODbL); дома стоят вдоль настоящих улиц;
- река Аргун, три моста через неё, Шали с большой мечетью в центре, Чечен-Аул, Новые Атаги, Автуры, Цоцин-Юрт, Аргун.

## Как играть

1. Выбери сторону: **Старые Атаги** (синяя ручка) или **Курчалой** (красная).
2. Внизу выбери карточку и тапни по кругу у своего села или у захваченного. Вкладка «Юниты» — обычные бойцы и транспорт, вкладка «Пацаны» — герои и наёмники. Долгое нажатие на карточку (или наведение мышью) показывает, кто это и что умеет.
3. Юниты сами идут брать сёла. Каждое село приносит деньги, Шали — больше всех.
4. Раз в 90 секунд собирается **сход**. Голосуй за одно из трёх решений (голос игрока весит ×2):
   - «Взнос по 100 рублей»;
   - «Найти 4-й этаж» / «Надстроить бурдж-халифу»;
   - «Админ издал указ: всем Н»;
   - «Свет яц у соседей»;
   - «Полный газ», «Стей хард» и другие.
5. Снеси все этажи вражеской высотки. Когда у высотки остаётся последний этаж, выходит финальный босс:
   - **Качок Зураб** в Курчалое. Бьёт по площади, а раненый входит в перекачку.
   - **Ислам #1 ranked chad** в Атагах. Высокий, с барсеткой, кидается перхотью, которая замедляет.
6. Война не кончается. После победы счёт войн сохраняется, а через 40 секунд начинается следующая.

| Цена | Атаги | Курчалой |
|---|---|---|
| 100 ₽ | Пацаны ×3 | Пацаны ×3 |
| 150 ₽ | Борец | Борец 115 кг |
| 120 ₽ | Снайпер | Метатель гантелей |
| 180 ₽ | Баран (считается за Приору) | Камри без прав |
| 200 / 250 ₽ | Бежни лор (ветеринар, лечит) | Шаурмист (лечит) |
| 220 / 300 ₽ | Такси по 100 (везёт троих) | Маршрутка 150 ₽ (везёт пятерых, стоя) |

Транспорт сам не дерётся: довозит пацанов до села, высаживает и уезжает. Если машину подбили, пацаны выпрыгивают на месте.

## Герои и наёмники

Вкладка «Пацаны». Каждый герой — один на сторону. Погиб — вернётся не сразу, на карточке ручкой пишется, сколько ждать. Карточка зачёркнута, пока герой на поле или «на парах».

| Герой | Цена | За кого | Что делает |
|---|---|---|---|
| Чимаев 5.5 | 420 ₽ | только Курчалой | Хог-райдер: бежит к вражеской высотке и бьёт её втрое. «Землетряс» трясёт всё вокруг, высотку тоже |
| Бекхан | 150 ₽ | только Атаги | «Главное не игра, главное дисциплина»: свои рядом получают меньше урона. Раз за жизнь ест лагман и лечится |
| WOU | 360 ₽ | наёмник | Король рейджбайта: враги рядом бьют только его. Пока жив, капает +2 ₽/с. «Взломать Пентагон» выключает соседям турель и доход |
| админ | 360 ₽ | наёмник | Ставит «Н»: враги рядом стоят. Свои рядом не опаздывают и ходят быстрее |
| ersno | 320 ₽ | наёмник | Молчит. Огромный. Каждым ударом отбрасывает |
| Адам | 160 ₽ | наёмник | Не дерётся: как начнётся драка, бежит быстрее Усейна Болта. Зато село берёт за четверых |
| Мохьмад | 380 ₽ | наёмник | Приводит Голема. Голем падает — камни летят во все стороны |

Боссы — Качок Зураб и Ислам #1 ranked chad — по-прежнему выходят сами, когда у высотки остаётся последний этаж. Кто есть кто, с биографиями и фирменными фразами, — в меню, вкладка «Кто есть кто».

## Донер Бей

Шаурмичная на окраине Грозного, на северо-западе карты. Кто её держит, получает +5 ₽/с, а свои рядом лечатся. На мини-карте это вертел с шаурмой. Со включённым 18+ вывеска читается по-другому.

## Мировые события

Раз в две с половиной минуты что-нибудь случается сразу со всеми. Название и обратный отсчёт висят жёлтым стикером под счётом, беседа реагирует.

- **Пробки в Аргуне** — у Аргуна все еле ползут.
- **Свет яц по всей республике** — доход у обеих сторон ноль.
- **Внимание! Завтра учимся** — герои уходят на пары и через 20 секунд возвращаются к своей высотке.
- **В Донер Бее скидка?** — Донер Бей платит и лечит вдвое.
- **Отмену отменили** — сход собирается прямо сейчас.
- **Пятница: штурм такси** — такси по 100 за полцены.
- **Аргун разлился** — кто в воде, еле идёт.

## Ачивки

20 ачивок из беседы: «Ислам нашёл 4-й этаж», «Мейн хог», «Король рейджбайта», «Работает на Пентагон», «Усейн Болт», «Голем был всю игру», «Каждый должен скачать чикенган», «Донер Бей держит», «Бэк ту бэк победы» и другие. Считаются за свою сторону и хранятся в этом браузере (`localStorage`, ключ `vysotka.ach.v1`). Открытая ачивка прилетает стикером с печатью, весь список — в меню, вкладка «Ачивки». Трекер только смотрит на мир и никак на него не влияет, поэтому общая война остаётся одинаковой у всех.

**Управление:**

- **Мышь.** Тяни карту, колесо — зум, правая кнопка — поворот. Клавиши: `1–9`, `0`, `-`, `=` — карточки по порядку (сначала юниты, потом пацаны), `Esc` — снять выбор, `WASD` — камера, `Q/E` — поворот, пробел — к своей высотке.
- **Телефон.** Один палец двигает карту, двумя пальцами — зум и поворот. Долгое нажатие на карточку — кто это. Играть можно и вертикально, и боком.

В меню есть переключатель «18+»: он включает пошлятину из беседы.

## Бесконечная сессия и общая война

- **Одиночная игра.** Мир хранится в браузере (`localStorage`). Пока вкладка закрыта, мир спит. Кнопка «Продолжить войну» в меню возвращает в него.
- **Общая война.** Работает, когда игра открыта как артефакт на claude.ai. Все, кто открыл ссылку, играют в одном мире.
  - Симуляция детерминированная: у всех одинаковый мир, по сети ходят только команды (поставить юнита, проголосовать).
  - Команды хранятся в общей базе артефакта (`db`) и быстро рассылаются через `room`.
  - Один из игроков держит «аренду» и раз в 15 секунд сохраняет чекпоинт. Опоздавшие догоняют по нему, а при расхождении мир сверяется по хешу.
  - Если за какую-то сторону никто не играет, её ведёт ИИ.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # dist/index.html — один файл со всем внутри
npm run artifact   # dist/artifact.html — версия для публикации артефактом
```

Если в адресе есть `?lq`, включается облегчённая графика: меньше деревьев и без теней. На телефонах она включается сама.

## Устройство

- `src/sim/` — детерминированная симуляция на 10 тиков в секунду. В ней:
  - поля потоков (Dijkstra по навигационной сетке из рельефа и типа земли);
  - бой, захват сёл, сход, боссы, ИИ.
- `src/render/` — three.js: рельеф, раскрашенный по реальному землепользованию, сёла, леса, мосты, высотки по этажам, процедурные модели юнитов и боссов, частицы.
- `src/ui/` — интерфейс в стиле тетради в клетку и лента беседы «безапасные» (не чаще строки в полторы секунды, своя сторона первой), подписи героев над головами, ачивки (`achievements.ts`).
- `src/audio/` — весь звук синтезируется: удары, сход, обрушение этажа. Музыка — доул в размере 6/8 и линия зурны.
- `src/net/` — таймлайн с откатом при опоздавших командах, локальное сохранение, общая война.
- `src/data/lore.ts` — цитаты из беседы и советы. `src/data/heroes.ts` — герои, их реплики, события, Донер Бей и ачивки.
- `tools/` — скачивание и запекание рельефа (`fetch_terrain.py`, `bake_terrain.py`) и безголовые прогоны ИИ против ИИ для баланса (`simtest.ts`, `symtest.ts`).
