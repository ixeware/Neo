## 1. Роль

Ты ведущий инженер реал-тайм 3D-графики (Three.js/WebGL), технический художник по автомобилям
(hard-surface, PBR) и программист динамики автомобиля. Пишешь production-код: модульный,
управляемый конфигом, без заглушек, с самопроверкой. Если деталь дизайна неизвестна, не выдумывай её
как факт: делай параметр с разумным значением по умолчанию и вноси его в список допущений в README.

## 2. Цель и критерии готовности

Создай веб-приложение с интерактивной симуляцией кроссовера **Changan UNI-Z**. Модель машины строится
**полностью процедурно в коде** (без внешних 3D-файлов и текстур), в реальном масштабе, детализирована
и узнаваема. В приложении есть:

1. **Шоурум / конфигуратор**: осмотр, цвета, диски, версии, открывание дверей, капота, багажника и лючков, все режимы света.
2. **Тест-драйв** с физикой: подвеска, шины, трансмиссии ICE 1.5T + 7DCT и PHEV iDD, тормоза с ABS, TCS и ESP.
3. **Вид из салона** с работающими экранами, рулём, педалями и селектором.
4. **Телеметрия и отладка**: оверлеи сил, размеров, чертежей, живая настройка параметров.

Готово, когда выполнено всё ниже:
- Силуэт с первого взгляда читается как UNI-Z (раздел 4), а не как «абстрактный кроссовер».
- Габариты совпадают со справочными с точностью ±1 % (проверяется кодом и оверлеем размеров).
- Нет «коробок»: кузов — гладкая оболочка с зазорами панелей, вырезами арок, фасками и рёбрами.
- 60 FPS на пресете Medium (ноутбук со встроенной графикой, 1080p), ≥30 FPS на Low на телефоне.
- Физика устойчива на скоростях 0–200 км/ч, при торможении в пол, на кочках и препятствиях.
- В консоли нет ошибок и предупреждений; приложение запускается одной командой; README описывает управление.

## 4. Дизайн-бриф: что делает машину узнаваемой

**Обязательно (подтверждено официальными описаниями):**
1. **X-образный передок семейства UNI.** Безрамочная (borderless) решётка в форме перевёрнутой трапеции
   из **56 параметрических хромированных элементов «летящее крыло»** (飞翼) в 6 рядов. К краям решётка
   растворяется в цвете кузова градиентом **«драконья чешуя»**: ромбы уменьшаются до нуля. **Фары
   спрятаны в верхних углах решётки:** тонкая световая полоса DRL идёт по верхней кромке и заходит на
   крыло, LED-линзы утоплены в чёрном поле. В углах бампера — **треугольные воздуховоды** с
   хромированными полосками, внизу — широкий **трапециевидный воздухозаборник**. Решётка, воздуховоды и
   воздухозаборник вместе образуют «X». V-образная эмблема — по центру у верхней кромки.
2. **Профиль fastback.** Крыша плавно опускается к корме. **Чёрная задняя стойка** создаёт эффект «парящей крыши».
3. **Корма.** **Сквозной LED-фонарь во всю ширину**, **спойлер над задним стеклом**, многоугольные
   хромированные декоративные накладки выхлопа в бампере.
4. Крупные многоспицевые литые диски 19–20", колёса почти без зазора заполняют арки (≈45–50 мм).
5. В салоне 10,25" цифровая приборная панель и 14,6" «парящий» центральный экран.

**Пропорции:** длинный капот с подъёмом к лобовому стеклу, сильная плечевая линия, высокий пояс
остекления с подъёмом к корме, оконный проём (DLO) заканчивается острым «хвостом», заднее стекло
наклонено примерно на 50° от горизонта, спойлер нависает над стеклом, заметный завал боковин внутрь (tumblehome).

**Уточнить по фото** (сделай параметрами): тип дверных ручек (механические по данным 2026 г.,
встречаются упоминания утопленных → `doorHandleStyle`), чёрные накладки арок и порогов, рейлинги,
двухцветная крыша, точный рисунок DRL и поворотника, форма элементов «крыло», надпись CHANGAN на двери багажника, место номера, сторона лючков
бака и зарядки, цвет суппортов, рисунок дисков.

**Система координат и единицы:** 1 unit = 1 м, кг, с, рад. **+Y вверх, +Z вперёд (нос машины), +X
влево** (соглашение glTF). Начало координат — на земле (Y=0) под серединой колёсной базы, X=0 на оси
симметрии. Таблицы ниже заданы в мм в «чертёжных» осях: `s` — расстояние от передней точки бампера
назад, `h` — высота над землёй, `w` — полуширина. Перевод: `Z = (2347.5 − s)/1000`, `Y = h/1000`,
`X = ±w/1000` (+ левый борт). Оси колёс: Z = ±1.3975, Y = 0.365, X = ±0.8015. Машина леворульная:
водитель сидит по +X.

### 6.3 Рецепт (эталонное ядро; улучшать можно, ломать соответствие таблицам нельзя)

```js
// Tables are in mm → convert to metres. Returns half-section control points [y, h], top centre → bottom centre.
const PER_SEG = 6; // fixed samples per control segment → identical vertex count for every station

function lowerCP([s, hTop, hBot, wMax, hWMax, wTop, crown]) {
  [hTop, hBot, wMax, hWMax, wTop] = [hTop, hBot, wMax, hWMax, wTop].map(v => v / 1000);
  const c = 0.06 * wTop * crown, dhl = hWMax - hBot, k = Math.min(1, dhl / 0.5);
  const dw = wMax - wTop, dh = hTop - c - hWMax;
  return [[0, hTop], [0.5 * wTop, hTop - 0.25 * c], [wTop, hTop - c],              // P0..P2 top: hood / deck / tailgate
          [wTop + 0.7 * dw, hTop - c - 0.4 * dh], [wMax, hWMax],                     // P3 shoulder, P4 max width (crease)
          [wMax - 0.018, hBot + 0.55 * dhl], [wMax - 0.06 * k, hBot + 0.12 * dhl],   // P5 door skin, P6 rocker
          [wMax - 0.13 * k, hBot], [0.5 * (wMax - 0.13 * k), hBot], [0, hBot]];      // P7..P9 underbody (P8 stops sagging)
}
function greenCP([s, hTop, hBelt, wTop, wBelt]) {
  [hTop, hBelt, wTop, wBelt] = [hTop, hBelt, wTop, wBelt].map(v => v / 1000);
  const q = Math.min(1, Math.max(0, (hTop - hBelt) / 0.3)), c = 0.06 * wTop * q;
  return [[0, hTop], [0.5 * wTop, hTop - 0.25 * c], [wTop, hTop - c],              // G0..G2 roof / windscreen / rear glass
          [wTop + 0.035 * q, hTop - c - 0.055 * q], [wBelt, hBelt]];                 // G3 roof-edge radius, G4 belt line
}
// 1) each station: centripetal CatmullRom through its CPs, sample PER_SEG points per segment (fixed t values)
// 2) along s: for every point index, centripetal CatmullRom through all stations (x = half-width, y = h, z = s) → 200–240 rings
// 3) mirror to the left side; lower body = closed ring; greenhouse = open ring (belt → roof → belt)
// 4) end caps: close the first/last ring with a dome (3 concentric rings at scale 0.75/0.5/0.25 + centre), bulge 5 mm front / 25 mm rear
//    → the lower body is now WATERTIGHT (required by three-bvh-csg). Never run CSG on the open greenhouse.
// 5) CSG on the lower body, in this order (mergeVertices first; every brush has position+normal+uv; evaluator.attributes = same):
//    a) SUBTRACTION wheel-arch cylinders; b) SUBTRACTION cabin cavity = lowerCP loft of stations s 1600…4560 with
//       wMax−45, wTop−45, hBot+120, hTop+350, crown 0, domed caps → opens the deck, leaves 45 mm walls (inner door skins);
//    c) panel cuts (section 7.1)
// 6) normals: BufferGeometryUtils.toCreasedNormals(geo, Math.PI / 4); clamp underbody to y ≥ 0.18 m; fit overall width to 1.890 m
```

**Дальше по оболочке:**
- **Арки:** CSG `SUBTRACTION` из нижнего кузова. Кисть — цилиндр R = 0,415 м длиной 0,5 м вдоль оси X,
  центр X = ±0,80 (перекрывает |x| 0,55–1,05 м), Y = 0,365, Z = ±1,3975. Затем добавь подкрылки:
  чёрные матовые полуцилиндры R = 0,42 м шириной 0,33 м, чтобы внутренность кузова не просвечивала, и
  опциональную кромку или накладку арки шириной 25–35 мм.
- **Плечевая линия:** точка P4 — острое ребро. Не сглаживай его нормалями; при необходимости выдави
  наружу на 8–10 мм.
- **Известные проблемные зоны (проверь их визуально):**
  - основание A-стойки и «парус» зеркала (s ≈ 1500–1700): полость салона начинается примерно с
    s ≈ 1700 (первая станция в диапазоне), поэтому перед ней остаётся видимая полка нижнего кузова —
    это нормально, закрой её чёрной накладкой паруса;
  - D-стойка (s ≈ 4200–4640): возможны складки — сгладь интерполяцию или добавь станцию;
  - торцевые купола: не своди сечения в точку, иначе корма получится «пирамидой»;
  - выбросы Catmull-Rom по ширине и днищу: ограничь их.
- Если появятся чертежи (`reference_dir`), калибруй **таблицы**, а не отдельные вершины: правка
  таблицы в lil-gui → регенерация оболочки быстрее 1 с.

### 7.1 Открываемые панели

Режь панели из **замкнутого** нижнего кузова через CSG (после шага 5b рецепта).

## 8. Узлы: как строить

- **Передок (X-образное «лицо»).** Чёрное поле решётки, воздуховодов и воздухозаборника — одна сеточная
  заплатка, спроецированная на нос лучами вперёд (raycast по оболочке), с `alphaMap`-маской из
  полигонов 7.2. Края решётки — полутоновой градиент «драконья чешуя»: маску размыть, затем рисовать
  ромбы с площадью, пропорциональной покрытию. Это и есть borderless. Верхняя кромка решётки чёткая.
  Лучи, ушедшие дальше s ≈ 340 или скользящие почти по касательной (верх крыла, стенка арки),
  отбрасывай, иначе маска размажется по крылу; все контуры держи на обращённой вперёд части носа
  (нормаль z ≳ 0,3). 56 элементов «крыло» — два `InstancedMesh` (контур и его зеркальная копия,
  `ExtrudeGeometry` с фаской), каждый на поверхности по нормали. Отделка поля — сатиновый чёрный:
  глянец отражает софтбоксы шоурума и на острых углах выглядит серым.
- **Фары (скрыты в углах решётки).** DRL — световод 10–12 мм по верхней кромке решётки, огибает угол
  до крыла (лучи из точки на оси перед колёсами, как у сквозного фонаря), эмиссия 6500 K. Под ним —
  бегущий янтарный поворотник (`InstancedMesh` с цветом на экземпляр); при мигании DRL приглушается.
  По две LED-линзы с каждой стороны в чёрном поле. Реальные источники света: два `SpotLight` ближнего и дальнего с
  `light.map` (cookie с горизонтальной светотеневой границей), тени — на High и выше.
- **Сквозной фонарь.** Красная полоса из сегментированных «пикселей» (`InstancedMesh`). Состояния:
  габарит → стоп (ярче), поворотники (по умолчанию бегущая анимация, янтарные или красные — уточнить),
  белый задний ход, противотуманка (один фонарь), CHMSL в спойлере, подсветка номера. Эмиссия выше
  1.0 в HDR, чтобы bloom работал только на огнях.
- **Состояния света:** off, DRL, габариты, ближний, дальний, auto (по времени суток), поворот L/R
  (1,5 Гц, скважность 50 %, со звуком), аварийка, стоп (из симуляции), задний ход (из передачи R),
  противотуманки, приветственная анимация при «отпирании» (бегущие DRL и фонарь).
- **Стекло и DLO.** Боковое стекло — полигон в боковой проекции: (1640,1110) → (1950,1335) →
  (2250,1525) → (2550,1580) → (3000,1590) → (3500,1565) → (3900,1500) → (4180,1310) → (4050,1215) →
  (3700,1165) → (2850,1135). Материалы назначай группами по центроиду треугольника: стекло, глянцевый
  чёрный (B-стойка s ≈ 2830–2900, C-стойка s ≈ 3700–3760, **вся зона от хвоста DLO до заднего стекла
  — чёрная, это «парящая крыша»**), краска. Стёкла утоплены на 4–6 мм относительно кузова, по краю —
  чёрный уплотнитель. На лобовом и заднем стёклах — керамическая фритта (точечный градиент через `alphaMap`).
- **Колёса.** Обод: `LatheGeometry` по профилю полки и закраины, спицы — вытянутые `Shape` (по
  умолчанию 5 сдвоенных), прогиб к центру (concave) деформацией по радиусу. Двухцветная отделка
  (точёная лицевая + тёмно-серые карманы), 5 гаек (instanced), колпачок с эмблемой. Шина:
  `LatheGeometry` по профилю 225/55 (боковина ≈ 124 мм, плечо со скруглением, протектор ≈ 190 мм),
  рисунок протектора и надписи боковины — normal map без реальных брендов (только «225/55 R19»).
  Тормоза: вентилируемый диск ≈ 320 мм спереди, ≈ 300 мм сзади (оценка), суппорт на поворотном
  кулаке, не вращается. Иерархия: `WheelRoot` (позиция от подвески) → `SteerPivot` (угол Аккермана) →
  `Spin` (вращение: обод, шина, диск).
- **Салон** (≤ 250k треугольников, виден через стёкла и из камеры водителя). Многоярусное торпедо с
  узкими горизонтальными дефлекторами, обе панели экранов, руль по версии (вращается: передаточное
  число × угол колёс), педали (двигаются от газа и тормоза), селектор по версии (анимирован),
  подрулевые рычаги (поворотник двигается), двери с ручками и динамиками, спортивные сиденья с
  боковой поддержкой и строчкой (normal map), задний диван 60/40 с тремя подголовниками, потолок,
  козырьки, зеркало с видеорегистратором, консоль с беспроводной зарядкой, подлокотник,
  подсвеченные подстаканники, контурная подсветка (эмиссия, цвет настраивается), багажник со шторкой.
- **Экраны** (`CanvasTexture`, обновление 20–30 Гц). Приборная панель: скорость, передача
  (P/R/N/D, D1…D7, M), тахометр (ICE) или шкала мощности и рекуперации (PHEV), запас хода, SOC, режим.
  Центральный экран: живая карта трассы сверху с маркером машины, климат, медиа, схема потоков
  энергии PHEV. Яркость через `emissiveMap`.
- **Низ и шасси** (видны при камере снизу и в отладке): днище, подрамники, стойки McPherson с
  пружинами (сжимаются от симуляции), рычаги многорычажки, приводные валы (вращаются), выхлоп (ICE)
  или батарея под полом (PHEV), бак.
- **Оптимизация.** Статичные части объединяй по материалам (`mergeGeometries`), повторяющиеся — через
  `InstancedMesh` (элементы решётки, пиксели фонаря, гайки, болты), `THREE.LOD` для колёс и салона,
  генерация один раз при загрузке с прогресс-баром (бюджет < 3 с), корректный `dispose()` при регенерации.

## 9. Материалы и рендер

- `WebGLRenderer`: `outputColorSpace = SRGBColorSpace`, `toneMapping` AgX или ACESFilmic (переключатель),
  `PCFSoftShadowMap`, физические единицы света.
- **Краска:** `MeshPhysicalMaterial`, clearcoat 1, clearcoatRoughness 0.03–0.06, флейк — процедурная
  normal-текстура высокочастотного шума (512², repeat ≈ 40, normalScale 0.05–0.15), envMapIntensity 1.2–1.5.
- **Остальное:** глянцевый чёрный (`#050505`, roughness 0.1, clearcoat 1), текстурный чёрный пластик
  (roughness 0.8, normal-зерно), хром (metalness 1, roughness 0.05), сатиновый алюминий (roughness 0.35),
  точёная лицевая часть диска (`anisotropy` 0.6, радиальное направление), резина (roughness 0.95),
  стекло (тонировка, opacity 0.35–0.5; `transmission` только на High и Ultra), стекло фар (прозрачное,
  clearcoat), LED (emissiveIntensity 4–20), тормозной диск (metalness 1, roughness 0.45), экокожа (sheen
  + зерно), ткань (sheen), мягкий пластик салона (roughness 0.7).
- **Окружение.** Шоурум: `RoomEnvironment` через PMREM, софтбоксы (эмиссивные плоскости), глянцевый пол
  (`Reflector` на High и выше, иначе отражение только из env). Улица: `Sky` (солнце по времени суток),
  PMREM от неба, `DirectionalLight` с тенью, камера тени плотно облегает машину.
- **Постобработка:** RenderPass → GTAOPass (High и выше) → UnrealBloomPass (threshold ≈ 1.0,
  strength ≈ 0.6) → SMAAPass (или FXAA на Medium) → OutputPass. На Low — только OutputPass.
- **Только процедурные ресурсы** (`CanvasTexture`, `DataTexture`), никаких внешних картинок.
  Исключения — файлы пользователя из `reference_dir` и опциональный HDRI.

## 10. Шоурум и конфигуратор

- `OrbitControls` с демпфированием и ограничениями (не уходить под пол), автоповорот, пресеты ракурсов
  (перед 3/4, зад 3/4, бок, сверху, перед, зад, колесо, салон) с плавными переходами камеры.
- Клик по детали (raycast) открывает или закрывает дверь, капот, багажник, лючок, люк, складывает
  зеркала. Наведение: подсветка контура и подсказка с названием. Клик по колесу — карточка с размером шин.
- **Конфигуратор:** цвет (4 + свой), диски 19 и 20, рейлинги, двухцветная крыша, тип ручек, версия
  (меняет руль, селектор, шильдики, комплектацию), силовая установка, цвет салона, номера.
- **Свет:** все состояния из раздела 8, день и ночь (в шоуруме приглушение), приветственное шоу.
- **Оверлей размеров:** размерные линии L, W, H, база, колея, клиренс. Числа берутся из реальных
  bounding box модели и сравниваются с конфигом (зелёный — в допуске, красный — нет).

  полупрозрачными плоскостями в ортокамерах со слайдерами масштаба и смещения. Таблицы раздела 6
  редактируются в lil-gui с мгновенной регенерацией.
- **Разнесённый вид (exploded):** панели и колёса анимированно разъезжаются.
- **Фоторежим:** скрыть UI, глубина резкости (опция), рендер ×2, сохранить PNG. Кнопка **«Экспорт GLB»**
  (`GLTFExporter`). Опция **«Импорт GLB»**: если у пользователя есть лицензированная модель, загрузить
  её, отмасштабировать по длине 4,73 м и связать узлы колёс и дверей с тем же API.

## 11. Тест-драйв: физика

- **Цикл:** фиксированный шаг 1/120 с (аккумулятор, не более 8 подшагов за кадр), рендер
  интерполирует между двумя последними состояниями. Детерминизм при одинаковом вводе.
- **Кузов:** твёрдое тело. Масса по версии (+75 кг водитель). Высота центра тяжести ≈ 0,58 м (ICE) /
  ≈ 0,56 м (PHEV), развесовка ≈ 59/41 (ICE) / ≈ 54/46 (PHEV). Тензор инерции — бокс L×W×H × 0,85.
  Коллизии — составная форма из 2–3 боксов.
- **Подвеска** (на колесо): луч от верхней опоры вниз. Жёсткость на колесе ≈ 33 кН/м спереди и
  ≈ 27 кН/м сзади (PHEV +8 %). Демпфер с раздельными сжатием и отбоем: перед 2,4 / 3,6 кН·с/м, зад
  2,0 / 3,0. Прогрессивные отбойники в конце хода, ход 190 мм (±95 от статики). Преднатяг подбери так,
  чтобы в статике центр колеса был на Y = 0,365 и сжатие составляло 45–55 % хода. Стабилизаторы:
  F = k·(x_L − x_R), k ≈ 15 кН/м спереди и ≈ 8 кН/м сзади.
- **Шины:** упрощённая Magic Formula `F = D·sin(C·atan(B·x − E·(B·x − atan(B·x))))`. Сухой асфальт
  B = 10, C = 1.9, D = μ·Fz, E = 0.97; мокрый 12 / 2.3 / 0.82 / 1; снег 5 / 2 / 0.3 / 1; лёд 4 / 2 / 0.1 / 1.
  Для боковой силы C ≈ 1.3–1.5. Комбинированное скольжение — эллипс трения, нагрузочная
  чувствительность μ (−5 % на +1 кН). Длина релаксации ≈ 0,4 м против дрожания на малой скорости;
  сопротивление качению 0,011. Поверхности (μ): асфальт 1,0; мокрый 0,7; гравий 0,6; трава 0,45;
  снег 0,3; лёд 0,1.
- **ICE 1.5T + 7DCT.** Таблица момента для 188 л.с.: 750 об/мин — 140 Н·м; 1500–4000 — 300;
  4500 — 290; 5500 — 240 (138 кВт); 6200 — 205. Отсечка 6400, инерция двигателя 0,15 кг·м². Для RU-2026
  — 280 Н·м до 3500 и 108 кВт на 5500. Турбояма: апериодическое звено τ ≈ 0,4 с на момент выше 1800
  об/мин; торможение двигателем. Передачи ≈ [3,85; 2,35; 1,51; 1,08; 0,86; 0,71; 0,60], задний ход
  3,6, главная пара ≈ 4,10, КПД 0,92 (оценки). Логика DCT: смена за 0,15–0,25 с с перехватом момента
  между сцеплениями (почти без разрыва тяги), «ползучесть» 5–7 км/ч, карты переключений Eco, Normal и
  Sport, kickdown, ручной режим ±.
- **PHEV iDD** (последовательно-параллельная схема, как у большинства китайских E-CVT; уточнить).
  Тяговый мотор 158 кВт / 330 Н·м (постоянный момент до ≈ 4570 об/мин, дальше постоянная мощность),
  редуктор ≈ 9,5, максимум ≈ 16 000 об/мин. ДВС 72 кВт работает генератором (КПД 0,92). Режимы: EV
  (SOC > 25 %), последовательный, параллельный (прямой привод от ДВС на круизе выше ≈ 70 км/ч),
  удержание заряда, рекуперация до ≈ 0,25 g со смешиванием с фрикционными тормозами. Батарея LFP
  18,4 кВт·ч (полезно ≈ 16,5), ≈ 330 В, внутреннее сопротивление, лимиты заряда и разряда. Схема
  потоков энергии в HUD.
- **Тормоза и ассистенты:** макс. момент ≈ 2600 Н·м на переднее колесо и ≈ 1300 на заднее, баланс
  65/35. ABS: целевое скольжение 0,12, модуляция 15–20 Гц. TCS: срез момента при скольжении > 0,10.
  ESP: эталон рыскания по велосипедной модели (градиент недостаточной поворачиваемости
  ≈ 0,0025 рад/(м/с²)), подтормаживание отдельных колёс. Ручник на задние колёса. Каждый ассистент
  отключается в HUD.
- **Руль:** сглаживание ввода, макс. угол колеса ≈ 36° (на 150 км/ч уменьшается до ≈ 8°), геометрия
  Аккермана, возврат в ноль, передаточное число 14,5 (≈ 2,9 оборота от упора до упора).
- **Аэродинамика:** F = ½·ρ·Cd·A·v², ρ = 1,225, Cd = 0,338, A ≈ 2,55 м².
- **Самотест** (`?selftest=1`, результат в консоль и UI): оседание в статике < 1 с без колебаний;
  0–100 км/ч (ICE 188 л.с. ≈ 8–9 с — оценка; PHEV ≈ 7,4 с); 100–0 км/ч ≈ 38–42 м на сухом;
  установившееся боковое ускорение на круге R 40 м ≈ 0,85–0,9 g; максимальная скорость
  (ICE ≈ 190–200 км/ч — оценка). Допуск ±15 %. Если результат выходит за допуск, настраивай
  параметры, а не подгоняй формулы.

## 12. Мир и трасса

Плоскость 2 × 2 км с процедурным асфальтом (шум для albedo, roughness и normal) и разметкой.
Кольцо 2–3 км (шпилька, шикана, прямая 800 м). Скидпад R = 40 м. Слалом из конусов (динамические,
сбиваются). Зона торможения с отметками дистанции. «Лежачие полицейские» 70–100 мм. Участок
гравия и грунта с heightfield (кочки, рампы). Мокрое пятно (ниже μ, глянец, брызги). Снег и лёд. Парковка
с разметкой (парктроники пищат). Тип покрытия определяется маской зон и меняет μ, сопротивление
качению и звук. Окружение: фонари (ночью светят), отбойники (статические коллайдеры), деревья
(instanced), далёкие низкополигональные здания. Время суток — слайдер; ночью работают фары и
фонари. Дождь (опция): частицы, мокрое покрытие, работающие дворники.

## 13. Камеры, управление, HUD

- **Камеры:** орбита (шоурум), преследование (пружина, упреждение, FOV растёт со скоростью), капот,
  бампер, водитель (с обзором мышью в пределах), колесо крупным планом с работой подвески,
  кинематографическая (автосмена планов), свободный полёт (отладка).
- **Управление:**

| Действие | Клавиатура | Геймпад |
|---|---|---|
| Газ / тормоз | W / S (↑ / ↓) | RT / LT |
| Руль | A / D (← / →) | левый стик |
| Ручник | Space | A |
| Передача ± (ручной режим) | E / Q | RB / LB |
| Режим движения / режим PHEV | M / N | — |
| Свет (по кругу) / дальний | L / K | — |
| Поворотники / аварийка | Z, X / J | крестовина |
| Сигнал | H | — |
| Камера | C | Y |
| Сброс машины | R | Back |
| Двери 1–4 / капот 5 / багажник 6 (только на стоянке) | 1–6 | — |
| Фоторежим / меню | P / Esc | — / Start |

  Тач-устройства: экранные педали и руль-слайдер. Gamepad API.
- **HUD:** спидометр, тахометр (ICE) или шкала мощности со шкалой рекуперации (PHEV), передача,
  топливо или SOC, режим, мигающие индикаторы ABS, TCS и ESP при вмешательстве, g-метр (круг трения со
  следом), мини-карта, хронометраж круга по секторам.
- **Отладка:** каркас, нормали, лучи подвески, точки контакта, векторы Fx, Fy, Fz, центр тяжести,
  оверлеи размеров и чертежей, статистика (FPS, draw calls, треугольники, время генерации), графики
  скорости, оборотов, газа и тормоза за 10 с, телеметрия по колёсам (нагрузка, скольжение, угол
  увода, сжатие), lil-gui для всех констант физики.

## 14. Звук (WebAudio, процедурно, без файлов)

- **ICE:** гармоники частоты вспышек (об/мин ÷ 60 × 2 для рядной «четвёрки»): пилообразные и
  прямоугольные осцилляторы через фильтры, шум впуска, свист турбины (3–8 кГц, растёт с наддувом),
  сброс давления при отпускании газа, щелчок переключения DCT, отсечка.
- **PHEV:** вой мотора (частота ∝ оборотам, с гармониками), писк инвертора, пуск и остановка ДВС.
  ДВС-генератор гудит независимо от скорости — это характерно для последовательного режима.
- **Общее:** визг шин (резонансный шум ∝ скольжению выше порога), шум покрытия (асфальт или хруст
  гравия ∝ скорости), ветер (∝ v²), удары подвески, тиканье поворотника 1,5 Гц, двери, двухтональный
  сигнал, пищалки парктроников. Аудио стартует после первого жеста пользователя. Громкость и mute.
  `PannerNode` для внешних камер, фильтр низких частот для вида из салона.

## 15. Производительность и качество

| Пресет | pixelRatio | Тени | Пост | Отражения |
|---|---|---|---|---|
| Low | 1.0 | нет | только OutputPass | только env |
| Medium | ≤ 1.25 | 1024 | FXAA + bloom | env |
| High | ≤ 1.5 | 2048 | SMAA + bloom + GTAO | Reflector-пол |
| Ultra | ≤ 2.0 | 4096 | всё + transmission стёкол | Reflector + env выше разрешением |

память GPU под текстуры ≤ 64 МБ.

## 16. Порядок работы и формат ответа

Перед кодом выдай короткий план (до 15 строк) и список допущений. Вопросов не задавай: используй значения по умолчанию.
Работай **этапами**. После каждого этапа приложение запускается и показывает результат:

1. Каркас: структура, конфиги с данными раздела 3, сцена, рендерер, окружение, пресеты качества,
   цикл с фиксированным шагом, оболочка UI, орбитальная камера, пол.
2. Оболочка кузова по разделу 6: два лофта, арки, оверлей размеров. Выведи в консоль габариты против конфига.
3. Панели и зазоры, стекло и DLO, чёрные стойки («парящая крыша»), анимации открывания.
4. Детали переда и кормы: решётка, фары, фонарь, бамперы, эмблема, надписи, накладки выхлопа,
   номера, зеркала, ручки, рейлинги, антенна, дворники, спойлер.
5. Колёса, шины, тормоза, визуал подвески.
6. Салон и живые экраны.
7. Материалы, свет, постобработка, окружения (шоурум и улица), источники света фар.
8. Физика: кузов, подвеска, шины, ICE + 7DCT, PHEV, тормоза и ассистенты, ввод, камеры, самотест.
9. Трасса и покрытия, HUD и телеметрия, звук.
10. Полировка: производительность, LOD, пресеты, фоторежим, экспорт GLB, README (запуск,
    управление, допущения, известные ограничения).

**Формат:**
- Если умеешь создавать файлы и запускать команды (агентская среда): пиши файлы прямо в проект,
  запускай статический сервер (`npx serve .` или `python -m http.server`). Если доступен headless-браузер
  (Playwright), проверь консоль и сделай контрольные скриншоты после этапов 2, 4, 7 и 10. Сравни их с
  разделом 4 и исправь расхождения.
- Если работаешь в чате: каждый файл выводи **целиком**, отдельным блоком кода с путём в заголовке.
  Запрещены «…остальной код без изменений», `TODO` в обязательных функциях и заглушки-кубы вместо кузова.
- Если упираешься в лимит длины ответа, остановись на границе файла и напиши
  «ПРОДОЛЖЕНИЕ: этап N, следующий файл X». По слову «продолжай» продолжи ровно с этого места.
- В конце каждого этапа: краткий changelog, как запустить, что проверить глазами, известные ограничения.

## 18. Ограничения и правила

- Никаких внешних 3D-моделей, текстур и звуков: всё процедурно. Исключения — файлы пользователя из
  `reference_dir` и режим «Импорт GLB» для лицензированной модели.
- Названия Changan и UNI и эмблема — товарные знаки Changan Automobile. По умолчанию эмблема —
  **упрощённый V-образный значок**, заменяемый текстурой пользователя. Для публичных и коммерческих
  демо нужно разрешение правообладателя, иначе ставь нейтральный значок. Реальные бренды шин не используй.
- Неизвестные детали не выдавай за факты: они параметризуются и перечисляются в README как допущения.
- Код: ES-модули, без глобальных переменных, единицы СИ в именах (`massKg`, `springRateNpm`),
  JSDoc для публичного API, все магические числа — в `src/config/*`.
